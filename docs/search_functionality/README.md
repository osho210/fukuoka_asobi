# 検索機能リファクタリング

## 概要
本ドキュメントは、福岡遊びアプリケーションの検索機能のリファクタリング内容をまとめたものです。

## 目的
1. コードの可読性・保守性を向上させる
2. 課金ユーザーに対する検索機能の付加価値を高める
3. エラーハンドリングの統一とユーザーフレンドリーなメッセージ提供

---

## 実施した変更

### 1. バックエンドのリファクタリング

#### 1.1 サービスクラスの分割
元々500行以上あった `PlanGenerator` を以下の6つのサービスクラスに分割:

1. **SpotFilterService** - スポットのフィルタリング処理
2. **SpotScoringService** - スポットのスコアリング処理
3. **SpotSelectionService** - スポット選定処理
4. **RouteOptimizationService** - ルート最適化処理
5. **TimeAllocationService** - 時間配分処理
6. **PlanCreationService** - 最終プラン生成処理

各サービスは単一責任の原則に従い、独立してテスト可能な設計となっています。

#### 1.2 エラーハンドリングの改善
カスタム例外クラスを作成し、エラーの種類を明確化:

- **PlanGenerationError** - プラン生成時の基本エラークラス
- **InvalidSearchParametersError** - バリデーションエラー
- **InsufficientSpotsError** - スポット不足エラー

#### 1.3 バリデーションロジックの分離
`SearchParamsValidator` サービスを作成し、バリデーションロジックを一元管理:
- 必須項目チェック
- 範囲チェック
- 型チェック
- 詳細なエラーメッセージの提供

#### 1.4 国際化（I18n）対応
エラーメッセージを `config/locales/ja.yml` に集約し、日本語メッセージを一元管理

#### 1.5 GraphQL エラー形式の統一
統一されたエラーレスポンス形式:
```json
{
  "plan": null,
  "errors": [
    "エラーメッセージ"
  ]
}
```

#### 1.6 日本語コメントの追加
すべてのメソッドに日本語コメントを追加し、コードの可読性を向上

#### 1.7 プレミアム検索条件の実装
課金ユーザー向けの高度な検索条件を追加:
- **決済手段**: クレジットカード、NFC、現金のみ
- **飲食店オプション**: 朝食、ランチ、ディナー、ベジタリアン、屋外席、子供向け、ペット可
- **その他**: 予約可、テイクアウト、デリバリー

---

### 2. フロントエンドのリファクタリング

#### 2.1 カスタムフックの作成
ロジックをカスタムフックに分離し、コンポーネントをシンプル化:

1. **useSearchParams** - 検索パラメータの状態管理
2. **usePlanGeneration** - プラン生成処理と状態管理
3. **useSearchValidation** - フロントエンドバリデーション

#### 2.2 コンポーネントの分割
`SearchContainer.tsx`（約150行）を以下のコンポーネントに分割:

1. **SearchForm** - フォーム表示とユーザー入力
2. **SearchResults** - 検索結果（生成されたプラン）の表示
3. **SearchContainer** - 状態管理とコンポーネント連携

#### 2.3 エラー表示の改善
エラーの種類に応じた適切な表示:
- バリデーションエラー: フォーム付近に表示
- 認証エラー: ログインページへリダイレクト
- プレミアムエラー: プレミアムプランへの誘導メッセージ
- システムエラー: 汎用エラーメッセージ

## コード行数の変化

### バックエンド
| ファイル | 変更前 | 変更後 | 削減率 |
|---------|--------|--------|--------|
| PlanGenerator | 約500行 | 約150行 | -70% |
| 新規サービスクラス | - | 約300行×6 | - |

**総行数**: 約500行 → 約2,100行（分割により増加したが、各クラスは150〜300行で管理しやすい）

### フロントエンド
| ファイル | 変更前 | 変更後 | 削減率 |
|---------|--------|--------|--------|
| SearchContainer | 約150行 | 約75行 | -50% |
| 新規コンポーネント/フック | - | 約300行 | - |

**総行数**: 約150行 → 約450行（分割により増加したが、各ファイルは100行以下で読みやすい）

## プレミアム検索機能

### 利用可能なプレミアムフィルター

#### 決済手段
- ✅ クレジットカード可
- ✅ NFC決済可
- ✅ 現金のみ

#### 飲食店オプション
- ✅ 朝食提供
- ✅ ランチ提供
- ✅ ディナー提供
- ✅ ベジタリアン対応
- ✅ 屋外席あり
- ✅ 子供連れ歓迎
- ✅ ペット可

#### その他
- ✅ 予約可能
- ✅ テイクアウト可
- ✅ デリバリー可

### プレミアム機能の動作
- 非課金ユーザーがプレミアムオプションを使用した場合、エラーメッセージが表示される
- 課金ユーザーは `user.paid_member?` メソッドで判定される
