# 日記（しおり）作成画面 ワイヤーフレーム - クイックリファレンス

## 📋 概要

このドキュメントは、福岡遊び日記アプリの「日記（しおり）作成画面」のワイヤーフレーム設計書のクイックリファレンスです。

詳細な設計内容は [`diary_bookmark_creation_wireframe.md`](./diary_bookmark_creation_wireframe.md) を参照してください。

---

## 🎯 4つのUIパターン

### 1. パターンA: 3カラムレイアウト（PC向け）

**対象ユーザー**: PC利用者、詳細編集が必要なユーザー

**特徴**:
- 左：スケジュール欄（タイムライン）
- 中央：地図表示（Google Map）
- 右：写真ギャラリー＋コメント

**メリット**:
- 全体を一画面で把握できる
- 編集作業が効率的
- マルチタスクに最適

**デメリット**:
- 小さい画面では情報が詰まる
- タブレット以下では不向き

**推奨利用シーン**: 詳細なプラン編集、大量の写真管理

---

### 2. パターンB: タブ切り替え型（スマホ・タブレット向け）

**対象ユーザー**: スマホメインユーザー、外出先での編集

**特徴**:
- 4つのタブで情報を整理
  1. スケジュール
  2. 地図
  3. 写真
  4. 設定

**メリット**:
- スマホ画面を有効活用
- 操作がシンプル
- 縦スクロールで完結

**デメリット**:
- タブ間の移動が必要
- 全体把握に時間がかかる

**推奨利用シーン**: 移動中の編集、簡易的な修正

---

### 3. パターンC: アコーディオン型（スマホ・タブレット向け）

**対象ユーザー**: 長いプランを管理するユーザー

**特徴**:
- 各スポットをアコーディオンで展開・折りたたみ
- 必要な情報だけ表示
- ミニマップをスポットごとに表示

**メリット**:
- スクロールがしやすい
- 情報の整理が容易
- 長いプランに最適

**デメリット**:
- 複数スポットの同時編集が困難
- 展開・折りたたみの操作が必要

**推奨利用シーン**: 5箇所以上の長いプラン編集

---

### 4. パターンD: ステップ形式（初心者向け）

**対象ユーザー**: 初めてプランを作成するユーザー

**特徴**:
- ウィザード形式で段階的に入力
- 4ステップで完了
  1. 基本情報
  2. スポット追加
  3. 写真追加
  4. 公開設定

**メリット**:
- 操作が簡単
- 必要な情報を漏らさない
- 初心者に優しい

**デメリット**:
- ステップ間移動が面倒
- 全体編集がしづらい
- 上級者には冗長

**推奨利用シーン**: 初回利用時、チュートリアル

## 🖥️ デバイス別推奨パターン

| デバイス | 推奨パターン | 代替パターン |
|---------|------------|-------------|
| **スマホ（縦）** | パターンB（タブ型） | パターンD（ステップ型） |
| **スマホ（横）** | パターンC（アコーディオン） | パターンB（タブ型） |
| **タブレット** | パターンA（2カラム版） | パターンC（アコーディオン） |
| **PC** | パターンA（3カラム） | - |

## 🚀 ユーザー利用フロー

### 作成フロー（5ステップ）

```
1. 基本情報入力
   ↓
2. スポット追加（3つの方法から選択）
   ↓
3. 詳細入力（写真・コメント）
   ↓
4. プレビュー確認
   ↓
5. 保存（下書き or 公開）
```

### 公開フロー（4ステップ）

```
1. 公開設定（公開範囲選択）
   ↓
2. タグ・サムネイル設定
   ↓
3. プレビュー確認
   ↓
4. 公開完了（URLが発行される）
```

### シェアフロー（3ステップ）

```
1. シェアボタンをクリック
   ↓
2. シェア方法選択
   - URLコピー
   - Twitter
   - Facebook
   - LINE
   - メール
   - QRコード
   ↓
3. シェア完了
```

## 🔧 主要コンポーネント

### 1. スケジュール欄（タイムライン）
- ドラッグ&ドロップで順序変更
- 時間の自動計算
- 移動手段・移動時間の編集

### 2. 地図表示（Google Map）
- マーカーで各スポットを表示
- ルートラインで移動経路を可視化
- 地図上から直接スポット追加
- ルート最適化機能

### 3. 写真ギャラリー
- ドラッグ&ドロップでアップロード
- サムネイル表示
- 削除・並び替え
- 一括アップロード対応

### 4. コメント入力欄
- リッチテキストエディタ
- 絵文字入力サポート
- テンプレート機能
- 自動保存

### 5. 画像サムネイル一覧
- グリッド/リスト表示切り替え
- スポット別フィルタリング
- 一括選択・削除

## 📱 レスポンシブ対応

### ブレークポイント

- **〜767px**: スマホ → パターンB or D
- **768px〜1023px**: タブレット → パターンC or A（簡略版）
- **1024px〜**: PC → パターンA（3カラム）

## 🛠️ 技術実装推奨

### 使用するライブラリ・API

| 機能 | 推奨技術 |
|------|----------|
| 地図表示 | Google Maps JavaScript API |
| ルート検索 | Google Directions API |
| スポット検索 | Google Places API |
| 写真アップロード | ActiveStorage + AWS S3 / Cloudflare R2 |
| ドラッグ&ドロップ | react-beautiful-dnd / @dnd-kit/core |
| 画像編集 | react-image-crop |
| リッチテキスト | react-quill / Lexical |

### データモデル拡張案

```ruby
# PlayPlanモデル
has_many_attached :images
# 新規フィールド: map_center_lat, map_center_lng, map_zoom_level

# PlanDetailモデル
has_many_attached :photos
# 新規フィールド: comment, photo_order
```

## ♿ アクセシビリティ

### キーボード操作

| 操作 | ショートカット |
|------|---------------|
| スポット追加 | Alt + N |
| 保存 | Ctrl + S (Cmd + S) |
| プレビュー | Ctrl + P |
| スポット間移動 | Tab / Shift + Tab |
| スポット順序変更 | Ctrl + ↑/↓ |

### スクリーンリーダー対応
- すべての画像にalt属性を設定
- フォーム要素にlabel要素を紐付け
- ARIAラベルで操作可能な要素を明示
