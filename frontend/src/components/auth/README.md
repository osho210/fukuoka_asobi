# 認証コンポーネント

このディレクトリには、ユーザー認証に関連するコンポーネントが含まれています。

## コンポーネント一覧

### 1. ログイン画面 (`Login.tsx`)

ユーザーがメールアドレスとパスワードを使用してログインするための画面です。また、GoogleとAppleのソーシャルログインも提供しています。

**機能:**
- メールアドレスとパスワードによるログイン
- Googleログイン
- Appleログイン
- バリデーション
- エラーメッセージの表示
- 会員登録ページへのリンク
- パスワード忘れページへのリンク

### 2. 会員登録フロー (`RegisterFlow.tsx`)

3ステップからなる会員登録フローを管理する親コンポーネントです。

**機能:**
- 3ステップの会員登録プロセス
- ステップ間のナビゲーション
- フォームデータの管理
- APIとの連携

### 3. 会員登録ステップ1 (`RegisterStep1.tsx`)

メールアドレスの入力ステップです。

**機能:**
- メールアドレスの入力
- メールアドレスのバリデーション
- 次のステップへの進行

### 4. 会員登録ステップ2 (`RegisterStep2.tsx`)

ニックネームとパスワードの入力ステップです。

**機能:**
- ニックネームの入力
- パスワードの入力
- 入力値のバリデーション
- 前後のステップへのナビゲーション

### 5. 会員登録ステップ3 (`RegisterStep3.tsx`)

性別選択と利用規約同意のステップです。

**機能:**
- 性別の選択（女性/男性/回答しない）
- 利用規約への同意
- 会員登録の実行
- 前のステップへのナビゲーション

## 使用方法

### ログイン画面の表示

```tsx
import Login from '@/components/auth/Login';

export default function LoginPage() {
  return (
    <div className="container">
      <Login />
    </div>
  );
}
```

### 会員登録フローの表示

```tsx
import RegisterFlow from '@/components/auth/RegisterFlow';

export default function RegisterPage() {
  return (
    <div className="container">
      <RegisterFlow />
    </div>
  );
}
```

## スタイリング

スタイルは `src/styles/Auth.css` に定義されています。このCSSファイルには、認証関連のコンポーネントで使用されるすべてのスタイルが含まれています。

## バックエンド連携

これらのコンポーネントは以下のAPIエンドポイントと連携します：

- ログイン: `/api/v1/login` (POST)
- 会員登録: `/api/v1/signup` (POST)
- ログアウト: `/api/v1/logout` (DELETE)
