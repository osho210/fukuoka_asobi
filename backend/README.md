## 🗃 データベース関連

### 🔹 データベースの作成

### データベースの初期化コマンド
```sh
rails db:migrate
```

GraphQLオブジェクトの生成コマンド
```sh
rails generate graphql:object モデル名
```

インストールコマンド
```sh
bundle install
```

サーバーの起動
```sh
rails server
```
